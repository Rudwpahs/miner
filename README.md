# Basketball Knowledge Miner

Public, zero-incremental-cloud-spend collector for Hooper's Hub / FormPath.

V1 is intentionally limited to academic/official basketball sources and explicitly allowlisted high-quality coaching/direct-expert material. It stores only public collection code and non-private checkpoint state. Private FormPath research-unit text, Coach data, raw video, full transcripts, and full copyrighted articles do not belong in this repository.

Development branch: `work/gpt-basketball-miner-v1`.
